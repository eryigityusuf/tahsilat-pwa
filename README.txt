NETLIFY'DA GÜNCELLEME
1. Bu ZIP'i bilgisayarınıza indirin.
2. ZIP'i klasöre çıkarın.
3. Netlify > namazyoklama.netlify.app sitenizi açın.
4. Deploys bölümüne girin.
5. Klasörün içeriğini manuel deploy alanına sürükleyip bırakın.
6. Yayın tamamlandıktan sonra:
   https://namazyoklama.netlify.app/
   adresini açın.
7. Eski sürüm görünürse tarayıcı önbelleğini temizleyin veya uygulamayı kaldırıp tekrar yükleyin.

Android:
Chrome > menü > Uygulamayı yükle / Ana ekrana ekle

iPhone:
Safari > Paylaş > Ana Ekrana Ekle
